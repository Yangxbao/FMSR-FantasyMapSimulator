### P7 性能
12 倍速时整图重建 ~200ms/次顿挫（需 chunked mesh）；边界串接+平滑首建 ~1-2s（Dijkstra 后又增）。选项：C# 模块或分块重建。

### P8 已修复勿回退
- `generate()` 幂等性（provinces/states 必须在开头 clear——否则"新世界"数据污染）
- 状态 ID 两段式生成（追加过程中 states.size() 变化会跳号）
- 山地图标必须用 Sprite2D 节点（draw_set_transform+纹理在主画布会渲染成实心方块，Godot 兼容渲染器批次问题）
- 15 列 CSV、Mods 目录位置、gameConfig 覆盖行为（见 §2）

### P9 GDScript 4.2 语法坑（实测踩过）
无 `? :` 三元（用 `if/else` 表达式）；`PackedVector3Array` 无 `reserve()`；无 `Vector2(int)` 构造；类型化数组返回需显式构造；内部类访问外部实例成员必须经 `owner_render.`；Dictionary 点访问 OK 但类型推断为 Variant（`: float` 显式标注）；**Git Bash heredoc 会吃反斜杠——写脚本文件用 Write 工具**。
