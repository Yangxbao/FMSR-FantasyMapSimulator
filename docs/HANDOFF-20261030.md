## 0. 项目目标（用户原话归纳）

1. 用 REA（github.com/morluto/rea）对已购 Steam 游戏 FantasyMapSimulator（AppID 3035500）做深度逆向分析；
2. 在独立工作区做**忠实还原原版**的重建版（用户明确纠正过：不是做同类型新游戏，要"照着这游戏逆向出来"，界面/交互/逻辑对齐原版）；
3. 尽可能产出 Android APK；
4. 修改版要有可扩展的 Mod 框架和可配置玩法参数；
5. 原版保持可用，所有写入只进工作区或游戏官方 Mods 目录；
6. 个人本地研究用途，不分发。

**用户最关心的验收点（原话）**：「那个游戏里面的国家和地区都能点进去选择」——即原版式国家/行省点击信息面板。

## 4. 重建版当前实现度（对照原版）

### 已还原 ✅
- 羊皮纸海面+坐标网格、陆地色块透纸纹、三级边界（海岸粗线/国界粗黑/省界细灰）、河流、城邑圆点（首都带环）、国家大字名（系统宋体）、地形图标（Sprite 方案）
- 顶部事件横幅 + 底部十按钮工具栏（生成地图/地图外观/菜单选项/历史记录/统计信息/设为壁纸/地图编辑/暂停游戏/倍速/常见问题，按钮文案与原版一致）
- 国家/行省点选面板（官方文案）；行省叛乱真实分裂建国；设首都
- 月度心跳模拟（战争/吞并/人口）、历史滚动、JSON 存读档（版本号兼容）
- 规则参数运行时 +/− 调整 + `user://mods/*.json` 规则 Mod
- 触屏：拖动/捏合缩放/长按=Shift

### 未还原（差距清单）
- 省份边界是格网直线段；原版是维诺图平滑多边形（**最大视觉差距**）
- 地图生成算法是"结构对应"（管线环节一致）而非参数级一致（原版参数藏在各子方法里，需继续反编译）
- 生物群系（biome）系统未实现（原版有 BiomeResource.json + 群系图编辑）
- 人物/家族/将领、宗教/文化对玩法的影响、附庸/朝贡、外交通牒 UI、战役地图（CampaignInfoSection）、攻击箭头、战争宣称虚线、高度图/行省笔刷编辑器
- 国家面板仅简化版（原版 266 成员：领袖候选人、战争子面板、历史分页等）
- 字体用系统宋体（原版为内嵌 Noto CJK TMP SDF）
- 配色/名称为自制（原版走文化包数据，可后续接）

## 5. 当前问题清单（P0→P3）

### P1 Android 真机验证未完成（验收硬指标）
- APK 已构建签名，但没有任何设备实测过。模拟器被 Windows 虚拟机平台未启用阻塞（见 §1）。
- 下一步二选一：① 用户启用虚拟机平台+重启 → 跑 `tests/start_emulator_and_install.bat`（自动装+截图）；② 用户提供 USB 调试真机 → `adb install -r build/FMSR-debug.apk`。
- 注意：APK 用 `gl_compatibility` 渲染器 + arm64，Godot 4.2.2 模板已装；导出命令在 docs。

### P2 Ghidra 反编译任务名错误（后台任务空转）
- 曾队列 `TimeManager$$UpdateMonthly` —— **该方法不存在**。正确目标名示例：`TimeManager$$Update`、`WarManagerV2$$StartWar`、`WarManagerV2$$ResolveState`、`SaveSystem$$WriteRootV2`。
- 任何方法名先查 `reports/methods-assembly-csharp.csv`（17,739 行真实名单）再反编译。
- 后台 java 进程（约 2GB）若还在跑旧目标，可直接杀掉重发。

### P3 山地图标渲染异常（已规避，根因未查明）
- 现象：`draw_set_transform` + `draw_texture_rect` 在游戏主画布中把图标画成实心方块；同一纹理/变换/尺寸在独立测试脚本中完美；AA 折线同画布也排除。
- 已改用 Sprite2D 节点层（引擎原生）规避，效果正确。根因疑似 Godot 4.2.2 兼容渲染器批次 bug，不再值得深挖，除非未来需要 canvas item 内联纹理。
- 贴图源：`assets/origin/mount16_64.png`（512px 原图缩 64px；运行时像素已验证正确）。

### P4 世界生成与原版的参数差距
- 结构对应但参数自定（cell 尺寸 4px、省份播种步长 11、扩张概率 0.92 等均为自定）。原版真实参数在 `CreateProvinces/ExpandProvinces/...` 各子方法机器码里，需要继续反编译（管线已通，单方法成本低）。
- 大字名无避让/旋转；原版有（含缩放随 zoom）。

### P5 原版存档第三方读写未通
- AES 加密容器，密钥与 KDF 在 `SaveSystem.WriteRootV2/EncryptString`（RVA 已知）。非主线（重建版有自己的 JSON 存档），若要"跨端读原版存档"再挖。

### P6 Puerts `main` 加密 TS 包未解
- 解密逻辑在 ts-loader 程序集（元数据已定位）。解开可获得原版高层逻辑源码级参考，收益大、成本中。

### P7 原版进程管理限制
- 原版以管理员运行+反篡改：非提权会话不能杀进程/发输入；启动测试后需用户手动点退出确认框。做原版自动化验证时用日志/文件断言，别依赖 UI 自动化。

### P8 工程杂项
- 重建版大地图重建（改色）在 480×280 格网、GDScript 下单次 ~200ms，12 倍速时会顿挫 → 需要 chunked mesh 或 C#/扩展。
- 边界折线串接算法对长边界性能未优化（首次 ~1s）。
- `fms_modkit.py` 中文输出在 GBK 控制台乱码（功能正常）。
