# FMSR（Fantasy Map Simulator 重建版）使用与构建指南

> 定位：对 FantasyMapSimulator（Steam AppID 3035500）的个人研究性逆向重建原型。
> 忠实度依据：REA+Ghidra 反编译的原版管线（见 reports/decompiled/）、原版 localization.csv 官方文案、原版资产提取（仅本地研究使用）。

## 1. 启动（Windows）

```bat
:: 方式一：启动器
E:\GameResearch\FantasyMapSimulator\启动FMSR.bat

:: 方式二：直接命令
E:\Godot\Godot_v4.2.2-stable_win64_console.exe --path E:\GameResearch\FantasyMapSimulator\source\fms-godot
```

## 2. 操作方式（对齐原版交互）

| 操作 | 效果 |
|---|---|
| 左键点国家国土 | 打开**国家信息面板**（改名/政体/首都/行省数/人口/自主外交/镜头跟随） |
| Shift+左键（触屏长按） | 打开**行省信息面板**（改名/当前人口/城市防御力/设为首都/发动叛乱） |
| 左键拖动 / 单指拖动 | 移动地图 |
| 滚轮 / 双指捏合 | 缩放（0.35x–8x） |
| 底部工具栏 | 生成地图/地图外观/菜单选项/历史记录/统计信息/设为壁纸/地图编辑/暂停游戏/倍速/常见问题 |

## 5. Mods（对应需求 F3/F4）

- 规则 Mod：把 JSON 放入 `user://mods/*.json`（即 `C:\Users\MR\AppData\Roaming\Godot\app_userdata\FMSR - Fantasy Map Rebuild\mods\`），
  键名：`war_chance_per_month` / `expand_pressure` / `pop_growth` / `battle_randomness`，新世界时自动加载。
- 运行时调整：菜单选项面板 +/- 实时改参。
- 原版游戏 Mod 工具（独立）：`source/fms-modkit/fms_modkit.py`（生成/安装/卸载文化包到原版官方 Mods 目录、备份式改原版配置）。

## 6. 已知问题与后续

1. 山地/树木图标已改为 Sprite 节点渲染（此前 draw_set_transform+纹理在游戏画布中出现整块方形渲染异常，图标测试单画布正常——Godot 兼容渲染器的批次问题，Sprite 方案规避）。
2. 省份边界为格网直线段串接，原版为维诺图多边形平滑边（后续：边界点噪声位移+平滑）。
3. 国家大字名暂未做避让与旋转。
4. 存档为 JSON 明文（版本号前向兼容）；原版存档为 AES 加密容器（密钥在 IL2CPP 内，Ghidra 管线已就绪可继续挖）。
5. 字体使用系统宋体（原版为内嵌 Noto CJK 的 TMP SDF）。

## 7. 逆向证据链（为什么这样做=照着原版）

- 原版官方说明（localization.csv `MapEditingInstructions`）：地图基于**维诺图**，行省=相邻 cell 组成，国家最小单位=行省；左键国家开国家面板、Shift+左键行省开行省面板 —— 重建版交互与结构照此实现。
- REA+Ghidra 反编译 `BurgsAndStateGenerator$$Generate`（reports/decompiled/）：原版管线
  `CreateProvinces → ExpandProvinces → CreateSeaProvinces → ExpandSeaProvinces → PlaceProvincialCapitalsByJitterGrid → CreateStates → ExpandStates → EnsureProvinceConnectivity → RecalculateProvinceState → SpecifyBurgAndProvince → InitCultureNameSet → InitEthnicAttribute → UpdateColor → GetSeaRoutes`
  与重建版管线逐环节对应。
- UI 结构依据元数据 dump 中 `StateInfoUI`（266 成员）/`ProvinceInfoUI`（124 成员）字段与官方文案键。
