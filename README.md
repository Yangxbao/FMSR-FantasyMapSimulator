## 🎮 下载即玩

到 [**Releases**](https://github.com/Yangxbao/FMSR-FantasyMapSimulator/releases/latest) 下载 `FMSR.exe`,双击即可运行 —— **单文件、免安装**(Windows 10/11 x64)。

## ✨ 玩法一览

| 系统 | 说明 |
|---|---|
| 🏰 国家管理 | 点击地图上的国家,查看并管理宣战、结盟、附属与军队部署 |
| 🚩 军队旗帜 | 每支军队一面旗帜:行军动画、战斗标记、实时兵力数字 |
| ⚔️ 战争系统 | 选择目标国与战争目标,军队自动开赴战场,停战时结算(割让 / 吞并 / 附属) |
| ⏱️ 时间控制 | 暂停 / 单步 / 1x / 2x / 4x,随时观察战局 |

## 🔨 从源码运行

1. 安装 [Godot 4.2.2](https://godotengine.org/download);
2. 克隆本仓库;
3. 用 Godot 打开 `source/fms-godot/project.godot`;
4. 按 **F5** 运行。

更多说明见 [docs/使用与构建指南.md](docs/使用与构建指南.md)。
