# FMSR - FantasyMapSimulator Rebuild

FantasyMapSimulator (Steam) 的 Godot 4.2 重建版（粉丝项目）。

## 下载即玩
**[Releases - FMSR.exe](https://github.com/Yangxbao/FMSR-FantasyMapSimulator/releases/latest)** —— 下载后双击运行（Windows 10/11 x64，单文件免安装）。

## 玩法
- 点击国家查看/管理（宣战、结盟、附庸、军队部署）
- 地图上每支军队一面旗帜：行军动画、战斗标记、兵力数字
- 战争：选择目标国与战争目标，军队自动开赴战场，停战结算（割省/吞并/附庸）
- 时间控制：暂停 / 单步 / 1x / 2x / 4x

## 从源码运行
安装 Godot 4.2.2，克隆本仓库，打开 source/fms-godot/project.godot，按 F5。
