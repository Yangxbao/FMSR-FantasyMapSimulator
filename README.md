# FMSR - FantasyMapSimulator Rebuild

FantasyMapSimulator (Steam) 的 Godot 4.2 重建版（粉丝项目）。

## 下载即玩
见 Releases：下载 FMSR.exe 双击运行（Windows x64 单文件）。

## 从源码运行
安装 Godot 4.2.2 → 克隆仓库 → 打开 source/fms-godot/project.godot → F5。

## 0. 一句话状态

**V5.2 用户新增四项全部落地**：①速度上限 4×（8× 移除）；②菜单选项全中文分类面板（模拟参数/全局开关/系统，含中文标签与开关复选）；③行军可视化——每支军队一面移动旗帜（preCell→currentCell 每帧插值动画），战斗省显示脉动 ⚔️ 标记；④宣战确认后红色箭头指向目标国（30 秒）+ 镜头拉向战场。
另修：跨海占领"海域 N"bug、边防军省号奇偶采样的空间条带 bug、_kill_state 幂等、minMonthBeforeWarEnd=24 结算下限。

**FMSR 已是可玩的核心循环游戏**：选国家 → 看信息 → 部署军队 → 选目标宣战（可选战争目标）→
军队行军/遭遇战 → 占领 → 停战结算 → 结盟/解除 → 历史/存档。**速度上限 4×（按指令移除 8×）**，
4× 下模拟 CPU ~15%，地图操作流畅。自动化测试 **223+ 断言全绿**（14 项测试套件）。

**启动**：双击 `启动FMSR.bat`。**战争演示**：
`Godot_v4.2.2-stable_win64.exe --path source\fms-godot -- seed=42 demo=1 shots=8,24`

## 2. 性能诊断与优化（V5.1+V5.2 实测数据）

| 指标 | 修前 | 修后 | 手段 |
|---|---|---|---|
| 地图重建触发 | 每次 tick（8×→每秒 ~8 次全图扫） | **仅归属变化时**（10 秒 demo 28 次→**2 次**） | 双级脏标记（terrain/ownership）+ `map_changed` 信号收窄到领土变化点 |
| 单次 rebuild 耗时 | 350ms（mesh 115 + borders 235） | 同值但**频率降 93%**；mesh 只在编辑/视图变化时 | `_dirty_terrain` 分支 |
| tick 耗时 | 110-180ms（随战争数增长，O(军²) 遭遇扫描） | **16-32ms 平坦**（**5-8× 提升**） | 省→军队索引 `_prov_armies`（每 tick 一次构建） |
| 4× 模拟 CPU | 卡顿明显 | **~15%** | 以上合计 |
| 军队图层 | _draw 全量重绘 | 节点池（Sprite2D，434 节点常驻，500ms 增量同步） | ArmyIconsLayer |
